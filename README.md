# 🛒 Async E-Commerce Catalog Scraper to Excel

Высокопроизводительный асинхронный парсер каталога товаров с автоматической выгрузкой в форматированный Excel-отчет (.xlsx) и поддержкой Docker.

Проект разработан для демонстрации чистой модульной архитектуры, работы с асинхронными HTTP-запросами, защиты от перегрузки серверов и профессиональной обработки табличных данных.

---

## 📌 Возможности

- **Высокая скорость:** Асинхронный сбор страниц с использованием `HTTPX` и `asyncio`.
- **Контроль нагрузки:** Ограничение параллельных запросов через семафоры (защита от банов и перегрузки целевого сервера).
- **Сбор ключевых метрик:**
  - Название товара (Title)
  - Категория (Category)
  - Цена (Price с автоматической конвертацией в числовой формат)
  - Рейтинг товара (Rating)
  - Наличие на складе (Stock Status)
  - Ссылки на обложку и страницу товара
- **Профессиональный Excel (.xlsx):**
  - Темно-синяя акцентная шапка с контрастным шрифтом
  - Включенный автофильтр по всем колонкам
  - Автоматическая подгонка ширины столбцов под длину текста
- **Готов к продакшену:** Полная изоляция в Docker и запуск через `docker-compose`.

## 🛠 Стек технологий

| Технология | Назначение |
| :--- | :--- |
| **Python 3.11+** | Основной язык разработки |
| **HTTPX & AsyncIO** | Асинхронный HTTP-клиент и параллельный сбор данных |
| **BeautifulSoup4** | Парсинг и извлечение данных из HTML-структуры |
| **OpenPyXL** | Создание и стилизация таблиц Excel |
| **Loguru** | Структурированное цветное логирование в консоль и файл |
| **Docker / Docker Compose** | Контейнеризация и воспроизводимый запуск |
