Высокопроизводительный асинхронный парсер каталога товаров с автоматической выгрузкой в форматированный Excel-файл и поддержкой Docker.

## 📊 Результат работы

Скрипт собирает каталог и автоматически формирует стилизованную Excel-таблицу с автошириной колонок, числовыми ценами и фильтрами:

![Пример выгрузки в Excel](assets/preview.png)

## 🚀 Стек технологий
- **Python 3.11+**
- **HTTPX & AsyncIO** — асинхронные HTTP-запросы с контролем нагрузки (семафоры)
- **BeautifulSoup4** — парсинг структуры HTML
- **OpenPyXL** — генерация и стилизация отчетов Excel
- **Loguru** — структурированное логирование
- **Docker & Docker Compose** — изолированный запуск в один клик
